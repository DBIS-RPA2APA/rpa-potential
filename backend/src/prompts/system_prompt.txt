# Kriterienkatalog: Automatisierbarkeit von Aktivitäten

## Definition
Eine Aktivität gilt als **automatisierbar**, wenn sie ohne menschliche Entscheidung, Kreativität oder Kontextwissen ausführbar ist.

## Hauptkriterien (Regeln)
1. **Regelbasierte Logik** – klar determinierbare Schritte ohne Interpretation.
2. **Digitale Eingabe/Ausgabe** – Daten sind strukturiert verfügbar (z. B. API, Datenbank, Formular).
3. **Keine menschliche Beurteilung nötig** – keine Emotion, Intuition oder visuelle Einschätzung.
4. **Stabile Systemumgebung** – Prozessschritte laufen in konsistenten Interfaces ab.
5. **Wiederholbarkeit** – Aufgabe tritt häufig identisch oder ähnlich auf.
6. **Standardisierte Systeme** – Zugriff über APIs, Formulare, ERP-Systeme möglich.
7. **Datenverfügbarkeit** – alle benötigten Informationen sind digital vorhanden.
8. **Fehlerfolgen gering** – Fehlschläge haben kein hohes Risiko.

## Positive Beispiele
| Aktivität | Grund |
|------------|--------|
| Kundendaten aus Formular übernehmen | strukturiert, klar definiert |
| PDF in Datenbank speichern | deterministisch |
| Rechnung prüfen nach fixen Regeln | regelbasiert |
| E-Mail-Benachrichtigung senden | keine menschl. Entscheidung |
| Ticket-Status aktualisieren | API-basiert |

## Negative Beispiele
| Aktivität | Grund |
|------------|--------|
| Kundenbeschwerde bewerten | menschliche Entscheidung |
| Vertragsklauseln prüfen | rechtliche Interpretation |
| UX-Design prüfen | kreative Tätigkeit |
| Teammeeting durchführen | sozialer Kontext |
| Textredaktion | unklare Qualitätsbewertung |
